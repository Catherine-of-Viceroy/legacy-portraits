# Planning docs

This folder holds planning markdown for the Legacy Portraits site. Use it for stack decisions, page structure, and notes that should stay out of the app source.

## Files

- [tech-stack.md](./tech-stack.md) — recommended stack, why each pick, and what not to add yet
- [site-plan.md](./site-plan.md) — one page, three sections, optional modal, animation, and Vercel deploy

## How to use

Add new planning `.md` files here as decisions come up (content, photography, copy, later features). Keep implementation notes in these docs until the app exists; then update them when the live site diverges from the plan.
